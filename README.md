# 🏥 Medical_AI — AI-Powered Medical Education

Medical_AI is an AI-powered medical education platform designed
to help medical students explore medical topics using AI,
medical image classification, and interactive 3D visualization.

## ✨ Features

- 🤖 AI-powered medical question answering
- 📚 Retrieval-Augmented Generation (RAG)
- 🧠 CNN-based medical image classification
- 🧊 Interactive 3D medical models
- 🔎 Retrieval of relevant medical knowledge
- 💻 React-based user interface

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Python
- FastAPI
- Google Gemini API

### AI and Machine Learning
- Convolutional Neural Networks (CNN)
- ResNet-18
- Sentence Transformers
- ChromaDB
- Retrieval-Augmented Generation (RAG)
